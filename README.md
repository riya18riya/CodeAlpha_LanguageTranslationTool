# 🌐 CodeAlpha - Language Translation Tool

## 📌 Project Description
This is a simple Language Translation Tool developed using Python and Tkinter. It allows users to translate text between multiple languages using the Deep Translator library.

## ✨ Features
- Translate text between different languages
- Simple and user-friendly GUI
- Supports multiple languages
- Input validation and error handling

## 🛠 Technologies Used
- Python 3.14.3
- Tkinter
- Deep Translator

## ▶️ How to Run
1. Install the required library:
   ```
   pip install deep-translator
   ```
2. Run:
   ```
   python main.py
   ```
